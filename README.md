# 🏗️ Architecture

```text
Streamlit Frontend
        │
        ▼
FastAPI REST API
        │
        ▼
Service Layer
        │
        ▼
SQLite Database
```

The application follows a layered software architecture that separates the user interface, business logic, API communication, and database operations into independent components. This design promotes scalability, maintainability, and clean separation of responsibilities.

---

# ⚙️ Application Workflow

1. User interacts with the Streamlit frontend dashboard.
2. The frontend submits requests to the FastAPI REST API.
3. API endpoints route requests through the service layer.
4. Business logic validates and processes the request.
5. SQLite stores or retrieves application data.
6. The API returns JSON responses to the frontend.
7. The dashboard refreshes to display updated project and task information.
