# Project Management Portal

## Overview

Project Management Portal is a full-stack software engineering project designed to demonstrate:

- Frontend Development
- Backend Development
- Database Integration
- CRUD Operations
- Git & GitHub Workflows
- Software Engineering Best Practices

## Technology Stack

- Python
- Streamlit
- SQLite
- Git
- GitHub

## Project Objectives

- Create projects
- Create tasks
- Assign priorities
- Track status
- Generate dashboard metrics
- Demonstrate full software development lifecycle
